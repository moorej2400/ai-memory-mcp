# Documentation Writing Standard

Use ASD-STE100 Simplified Technical English for project documentation.
Use Issue 9, dated January 2025.

The [official standard](https://www.asd-ste100.org/assets/files/ASD-STE100_ISSUE9.pdf) is the primary reference.
The [official FAQ](https://www.asd-ste100.org/STE_faq.html) gives additional explanations.

This project guide does not replace the official standard.
Use the official standard if this guide has insufficient information.

## Scope

Apply the standard to new or changed technical documentation.
This scope includes README files, guides, procedures, command help, and user-facing error text.

Keep exact source identifiers unchanged.
Treat API names, commands, paths, and project terms as technical terms.

## Descriptive text

- Use active voice.
- Give information gradually.
- Use one topic in each sentence.
- Use a maximum of 25 words in each sentence.
- Use one topic in each paragraph.
- Use a maximum of six sentences in each paragraph.
- Use the same term for the same item.

## Procedural text

- Use the imperative form.
- Use a maximum of 20 words in each sentence.
- Put a required condition before the instruction.
- Put one instruction in each numbered step.
- Use two instructions only when the actions occur at the same time.
- Put results or limits directly after the related instruction.
- Do not put an instruction in a note.

## Word use

- Use approved STE words when possible.
- Use each word with one meaning.
- Use the same part of speech for each approved word.
- Do not use contractions.
- Avoid unclear pronouns.
- Avoid unnecessary words that end in `-ing`.
- Use technical nouns and technical verbs when the subject requires them.

## Review checklist

Before you finish a documentation change, do these checks:

1. Check the sentence length.
2. Check the paragraph length.
3. Check each sentence for one topic.
4. Check each paragraph for one topic.
5. Replace passive voice with active voice when possible.
6. Remove contractions.
7. Make terminology consistent.
8. Check all commands.
9. Check all links.
10. Compare the text with the official standard.
